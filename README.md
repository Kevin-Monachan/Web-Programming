# Web Programming Lab

A collection of Web Programming lab experiments developed using HTML, CSS, JavaScript, PHP, and MySQL.

## Objective

The purpose of this lab is to understand the fundamentals of web development including frontend design, client-side scripting, server-side scripting, form validation, event handling, and database connectivity.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL

## Programs Included

### HTML Programs

1. Demonstration of basic HTML tags  
2. Linking pages, images, tables, and internal links  
3. Frames in HTML (floating, navigation, mixed frames)  
4. Inline, internal, and external CSS styles  
5. HTML Registration Form  

### JavaScript Programs

6. String and Math object functions  
7. Calendar generation using JavaScript  
8. Form validation using JavaScript  
9. Background color change using event handling  
10. Mouseover event to change image and text  
11. Online examination page  

### PHP Programs

12. Registration form with validations  
13. Electricity bill generation using tariff calculation  
14. Student array sorting using `print_r`, `asort`, and `arsort`  
15. Display Indian Cricket players in HTML table  
16. Database connection and data retrieval using PHP  
17. Web application development and deployment  
18. Library Management using PHP & MySQL

## How to Run

### HTML/CSS/JavaScript Programs

1. Download or clone the repository
2. Open the HTML file in any web browser

### PHP Programs

1. Install XAMPP/WAMP server
2. Copy project folder into `htdocs`
3. Start Apache and MySQL
4. Open browser and run:

```text
http://localhost/project-folder/
```

## Database Requirements

- MySQL Database
- phpMyAdmin (recommended)

Import the SQL file if provided before running database-related programs.
